# Imobiliária

## Objetivo
Este aplicativo tem como objetivo permitir a gestão de reservas de um espaço de trabalho compartilhado (cowork)

## Telas

### Clientes
Esta tela exibe clientes que foram cadastrados.

<img src="https://raw.githubusercontent.com/mbatalha0595/aplicativo-reservas/main/images/TelaClientes.png" width="750">

### Informações do Cliente
Esta tela permite consultar informações do cliente

<img src="https://raw.githubusercontent.com/mbatalha0595/aplicativo-reservas/main/images/TelaClientesExibir.png" width="750">

### Cadastro
Esta tela permite realizar o cadastro de clientes.

<img src="https://raw.githubusercontent.com/mbatalha0595/aplicativo-reservas/main/images/TelaCadastroClientes.png" width="750">

### Histórico de Reservas
Esta tela permite consultar o histórico de resevas do cliente.

<img src="https://raw.githubusercontent.com/mbatalha0595/aplicativo-reservas/main/images/TelaClientesHistorico.png" width="750">

### Reservas
Esta tela permite realizar a reserva de clientes, sendo necessário apenas escolher o dia e a mesa na planta. Se estiver na cor vermelha, significa que está ocupada, caso contrário, está disponível para reserva.

<img src="https://raw.githubusercontent.com/mbatalha0595/aplicativo-reservas/main/images/TelaReservas.png" width="750">
